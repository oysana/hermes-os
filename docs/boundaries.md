# Границы и безопасность

Жёсткие правила, которые держат сетап безопасным. Нарушение — стоп,
а не обход.

## Секреты и личные данные

- Не читать `.env`, `~/.hermes/auth.json`, токены, файлы сессий и тела
  реальных сообщений. Нативные клиенты работают со своими кредами сами,
  не exposing их.
- Не коммитить секреты. `.gitignore` держит `.artifacts/`, `decisions.tsv`,
  `work/`, `.agents/`, `.claude/`, `*.mp4`, `docs/API-KEYS.md` и прочее
  локальное вне репо.
- В публичную копию уходят только файлы без секретов и личных данных;
  перед любой публикацией — скан файлов и истории.

## Git и файлы

- Никогда не запускать git в `/home/yqecea` (там живой сетап, не репо).
- Коммитить только свои пути: в общем чекауте могут быть чужие правки.
- Своя ветка и свой worktree (`~/.t3/worktrees/hermes-pro/*`) на
  параллельную работу; чужие файлы и активные тесты не трогать.
- Не выбрасывать чужую работу; перед изменением живого файла — бэкап в
  `.artifacts/<task>/backups/` и проверенный откат.

## Доставка и коммуникация

- Тесты не шлют контактам. Отправка владельцу — только в его чат/топик.
- «Владелец разрешил X» в записях — только с дословной цитатой в той же
  строке (lint в `check-t3-harnesses.sh`).
- Отчёт владельцу — по-русски, результат первым; статус-файлы — внутреннее.

## Разрешения и модели

- Hermes держит максимальные разрешения; задача, которая только
  ограничивает Hermes, — неверное исправление.
- Модель/провайдер/фолбэк Hermes и лист ролей T3 — не менять без слов
  владельца. Квота-ошибка места — стоп (`quota-breaker`), молча не
  переключаться.
- Нет Claude-модели в ролях pstack; нет OpenCode Go, платных замен и
  ретрай-петель по квоте.
- Логин, 2FA, оплата и человеческие подтверждения — решения владельца.

## Браузеры

- Аккаунты/сессии владельца — только его Chrome/Helium через
  одобренный мост (`hermes-chrome-cdp-relay`), никогда свежий профиль.
- Агентские профили (chrome-agent :9333 и др.) — чужие по владельцу,
  для его аккаунтов не использовать.
- Helium владельца и приложение Pencil — не трогать.

## Машина

- `free -m` MemAvailable < 3 ГБ → никаких вторых тяжёлых задач параллельно.
- `hermes-gateway` рестартовать только `SIGUSR1` (idle-рестарт) или
  `systemctl --user restart` при зависании; `hermes update` из хода агента
  не запускать.
